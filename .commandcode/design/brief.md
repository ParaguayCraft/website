# ParaguayCraft Website — Design Constitution

## Register: Brand

This is a marketing/promotional landing page. Every visual decision is a creative choice.
The emotional reaction at arrival is the deliverable. The visitor decides to join the server.

## Users and Context

- **Primary**: Paraguayan Minecraft players arriving to check server info, copy IP, join Discord
- **Pressure**: 2-second verdict — "is this a real, active server?"
- **Context**: Desktop (70%), mobile (30%), likely younger audience

## Core Job: Decide

The visitor must decide to join. The page needs:
- A focused pitch (cinematic hero)
- Proof the server is active (live status, player count)
- Risk reduction (feature overview, community size)
- One dominant action (JUGAR AHORA)

## Voice

- Cinematic survival atmosphere — torch-lit, medieval Paraguayan castle, warm dusk
- Nacional pride — flag colors as earned identity, not decoration
- Premium Minecraft network — not generic, not childish
- Spanish interface

## Anti-References

- Generic SaaS landing page (centered hero + 3 cards + CTA + footer)
- Colorful/childish Minecraft template sites
- Default Bootstrap/endless shade dark templates
- Blue-purple tech gradients
- Over-reliance on glassmorphism

## Visual Foundation

- **Palette**: Dark base (#080b0d) with Paraguayan red (#d62f2f), blue (#2455a4), white (#f1f1ed)
- **Type**: Display (Minecraft-style block font) + body (Inter)
- **Depth**: Opaque elevation with shadow, no blur dependency
- **Composition**: Asymmetric feature grid, left-anchored content where appropriate

## Design Principles

1. Palette has project-level justification — flag colors, not category reflex
2. Type is intentional two-font system — display for identity, body for readability
3. Motion explains behavior — fade+slide reveals, press feedback, status transitions
4. Every state is designed — loading, empty, error, success, offline
5. The castle must be visible — it's the proof object
